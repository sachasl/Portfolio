# Sacha Loi – Portfolio Website

This repository contains my personal portfolio website, created to showcase my projects, skills, and experience as a Computer Science student at the University of Warwick.

## About
This portfolio was developed as part of a Portfolio Website Workshop and serves as a central hub for my work, including:
- Programming projects
- Technical skills
- Links to my GitHub and LinkedIn
- Contact information

## Technologies Used
- HTML
- CSS (Bootstrap 5)
- JavaScript
- Bootstrap Icons

## Features
- Responsive design (mobile-friendly)
- Navigation bar with quick links
- Project showcase section
- Skills overview
- Contact section with email, GitHub, and LinkedIn
- CV view functionality
